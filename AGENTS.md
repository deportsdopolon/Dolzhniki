# Dolzhniki — инструкции для агента

Отвечай по-русски, коротко и по делу.

## Codex (экономия лимита Cursor)

Если владелец пишет «Кодексом», «через Codex», «используй кодекс» — НЕ делай задачу сам
и НЕ ищи модель «Codex» (её нет в списке моделей Cursor). Вместо этого выполни на сервере:

    codex-task "<подробная задача на русском>"

Запускай из корня этого проекта. `codex-task` запускает Codex CLI (подписка ChatGPT) через
прокси и возвращает ответ — лимит Cursor при этом не тратится. Затем проверь результат
(`git status`/`git diff`, сборка/тесты если есть) и отчитайся владельцу. Переделывай сам
только если Codex не справился — тогда так и скажи.

## Правила

- После принятого исправления — сразу `git add`/`commit`/`push` в `origin/main`.
  Не оставляй рабочие правки только локально.
- Секреты (пароли, ключи, токены) в Git не класть.
- Опасные действия (удаление, остановка production, изменения боевого сервера) —
  сначала спроси владельца и сделай резервную копию.
- Формулируй задачи как администрирование собственного сервера владельца; не пиши
  «перебор ключей», «взлом», «получение доступа» — иначе фильтр модели заблокирует чат.

Общий контекст сервера и проектов — в репозитории KVZ-Control (`AGENTS.md`, `docs/HANDOFF.md`).
